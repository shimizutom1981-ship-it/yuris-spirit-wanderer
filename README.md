# ユリス・霊流の旅人

小説「ユリス」の世界を舞台にした、見下ろし型のブラウザRPGです。街の人との会話、機霊との出会い、広いフィールドの探索を楽しめます。

## v0.4 の内容

- 232×168マスの世界。ノルヴィク、リーネ村、水鏡修道院、風待ち港、灰石の廃鉱、潮鳴りの灯台。
- 草原・森・湿原の街道、道中の敵、野営地。
- 敵が画面の視界に入ると始まる同一マップ上の戦闘。木や壁による遮蔽、夜の視界。
- 仲間の隊列と一人ずつの戦闘行動。武器・防具・盾・アクセサリー20種、魔法6種。
- 弓の射程・矢の消費、装備の持ち替え、荷物の受け渡し。
- 第一章と第二章「三つの記憶」。会話・読書・道具・複数の解法と結末。

登場人物・地図・ドット絵・音楽は本作向けのものです。元の `yuris-rpg` とは別のゲームです。

## 遊び方

方向キーか画面の十字ボタンで移動。地図をタップして移動・会話・調査もできます。Aキーまたは「コマンド A」でメニュー、Bキーまたは「戻る B」で戻ります。音は初期状態でOFFです。

戦闘では、生きている仲間全員が1回ずつ行動した後に敵が行動します。戦闘外では前の仲間の足跡を追って歩きます。仲間のいるマスへは重なれないため、折り返しは横に一歩ずれて行います。

セーブは使用中のブラウザのlocalStorageに自動保存します。サイトのURLが変わると保存領域も変わるため、以前のSites版のセーブはGitHub Pagesへ自動転送されません。同じURLでの旧版セーブは移行できます。

## ローカル実行

ビルドやパッケージのインストールは不要です。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000/` を開きます。

## テスト

Node.js 24で次を実行します。外部パッケージは不要です。

```sh
node test.cjs
node field-test.cjs
node qa-ui.cjs
```

経路・衝突・戦闘・保存移行・隊列・シナリオ・装備と魔法を検証します。UIハーネスは実ブラウザ試験とは別です。

## GitHub Pages

リポジトリの Settings → Pages → Source を **GitHub Actions** に設定します。`main` への更新時にテストを実行し、成功すると `dist/` を公開します。Actionsの `Test and publish game` は手動でも実行できます。

## ソース管理

このリポジトリをソースの正本として管理します。変更はcommitに残し、機能・修正と検証内容を `CHANGELOG.md` に記録します。既存のSites版とは自動同期されません。
